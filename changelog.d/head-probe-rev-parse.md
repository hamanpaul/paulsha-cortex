### Fixed

- **#716 canary HEAD proof 接受唯讀的多旗標 `rev-parse` 等歷史形狀**：canary run 37375402971 跑完全部 live 階段，結案時仍找不到 HEAD proof——codex 這次寫成 `git rev-parse --show-toplevel --git-dir --git-common-dir HEAD && git worktree list --porcelain && git status --short && sed -n '1,120p' <plan>.md`，整條 exit 0、bound HEAD 單獨成行，但比對器只收 `rev-parse [--verify] HEAD`，判為 `accepted=False`。`rev-parse` 改為：位置參數恰好一個且為 `HEAD`／`HEAD^{commit}`／`@`，選項全在唯讀查詢允許清單內（`--verify`、`--show-toplevel`、`--git-dir`、`--absolute-git-dir`、`--git-common-dir`、`--is-inside-work-tree`、`--is-inside-git-dir`、`--is-bare-repository`、`--is-shallow-repository`、`--show-prefix`、`--show-cdup`、`--show-object-format`、`--show-superproject-working-tree`、`--path-format=absolute|relative`；`-q`／`--quiet` 只能搭配 `--verify`）即可當 proof。會改變 HEAD 那一行印法或印出其他值的選項（`--short`、`--abbrev-ref`、`--symbolic`、`--symbolic-full-name`、`--sq`／`--sq-quote`、`--not`、`--local-env-vars`、`--git-path`、`--default`、`--all`、`--prefix`、`--`）與任何沒列出的選項一律不收。`log`／`show` 另接受 `HEAD^{commit}`／`@` 與 `-n 1`／`--max-count 1`，格式仍只收 `%H`；git 全域選項另接受 `--no-pager`。proof 仍須整條 exit 0、每段都是允許的唯讀段，且輸出含 bound HEAD 那一行（#716）。
