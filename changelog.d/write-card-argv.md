# write-card-argv

- **#716（選項 B 的後半）：寫入卡的 argv 切換——`builder-workspace-write` 那一列改發 `-s danger-full-access`，且不再附 `--enable use_legacy_landlock`。** 前置（PR #725 的出口管制）已部署並實機驗證（白名單內通、白名單外拒、任意命令四條 DIRECT-BLOCKED、busctl 拒），「不補出口就不要採 B」成立。`workspace-write` 在 legacy landlock 下 **100% panic rc=101**（`linux_run_main.rs:318`，session 層級、先於任何命令）——對寫入卡「內層沙箱」不是防護，是讓每張卡必死的東西；`danger-full-access` ＋ 該旗標實測是無意義殘留，只會在 job log 開頭多印一筆 deprecation 的 error item。**只動導出表與其消費端**（`registry.SANDBOX_MODE_DERIVATION`），`build_codex_argv` 沒有第二個 `if`（#720 的結構守住）。
- **附掛條件跟著契約走**：表上新增 `attaches_inner_sandbox` 欄，`launcher._codex_inner_sandbox_argv()` 依 `derive_job_write_contract()` ＋ `inner_sandbox_attached_for()` 決定附不附——read-only 族**維持** legacy landlock（今天是好的、真的在擋），`danger-full-access` 那列**不附**（沒有內層可附），bypass 不附。與 mode 的一致性（附 ⇔ mode 是 `read-only`）、**`workspace-write` 不得再上表**（100% 必死卡）、`grants_filesystem_write` 的誠實語意（`danger-full-access` ⇒ True ＝「連內層都沒有」）全部在 registry **import 期斷言**釘死。該列 note 逐字記下殘餘防線：**systemd 外層 ＋ 出口管制**——七個面向外層零成本接得住（#716 涵蓋面對照第 2 節）、出口已補（PR #725）、#718 記著今天就存在的四個缺口（`$CODEX_HOME` 非 hooks.json 面可寫、commit-spool／event-spool 整棵可寫、資源零上限）。
- **刻意不用 `--dangerously-bypass-approvals-and-sandbox`**：`build_codex_argv` 把它與 `--dangerously-bypass-hook-trust` 綁在一起，會連 #698 封住的 hook 信任閘一起關掉；`allow_unsafe`（UNSAFE_BYPASS）那列維持原樣，它是另一個顯式 opt-in。**三列不變**：planner／reviewer read-only 與 builder write-forbidden 的 argv **byte-identical 不變**，由 `tests/test_write_card_argv_716.py` 的黃金釘子（變更前實抓的字面 list）釘住；同檔另釘 `danger-full-access` 列的 argv 形狀，含「不帶 legacy landlock 旗標」「不帶 `--dangerously-bypass-*`」兩個負向斷言。
- **核可閘已量（涵蓋面對照第 6 條的「未量到」補上）**：0819 真實加固面複本（`psc_run_under` 全量導出 54 條 property、`</dev/null`）＋ 真實 `codex exec` 一次——headless `-s danger-full-access` **不卡核可閘**：模型自主跑兩條命令（`git rev-parse HEAD` 因 dubious ownership exit 128 → 自行改 `git -c safe.directory="$PWD"` exit 0）、`turn.completed`、rc=0，全程零 approval 請求，不需要 `--approve-for-me`；串流開頭也**沒有** deprecation error item（旗標拿掉的直接效果）。
- **探針語意更新**：`emitted_sandbox_modes()` 由 `('read-only','workspace-write')` 變 `('read-only','danger-full-access')`。`permgen.build_inner_sandbox_probe()` 分兩族——附掛內層的 read-only 族維持四步矩陣（負向對照＋旗標還在＋正向＋真的在擋）；`danger-full-access` 那列**沒有內層沙箱**，**不拿 `codex sandbox` 驗它**（rc=0 只證明「沒有沙箱」），改斷言 (a) 命令執行得了（`PSC-716-EXEC-OK` rc=0）與 (b) **出口管制在**（`/usr/bin/env -u HTTPS_PROXY … socket.create_connection(("1.1.1.1",443))` 必須 `TimeoutError`）——(b) 是該列僅存的網路防線，探針缺了它就是假綠。a/b 兩段已在真實加固面複本下實跑：a → `PSC-716-EXEC-OK` rc=0、b → `TimeoutError: timed out` rc=1，與產出的期望逐字一致。分族判準由 `registry.sandbox_mode_attaches_inner_sandbox()` 機械導出；產生器的 fail-closed 由「必含 workspace-write」改為「不得只剩唯讀族」（同樣擋 #715 那型假綠）。runbook 4e-2g／4e-2h 期望值同步更新，新增 4e-2j 段。
- **誠實邊界**：B 至此兩半齊備（出口管制 ＋ argv 切換），**但端到端（真實派工跑會寫檔的卡，例如 tdd-red）尚未驗**——那一條才是驗收，記在 4e-2j 驗證 3 與探針的「量不到」清單。加固面 diff 為空，八份 unit 逐字不變，零部署動作（部署＝更新 cortex 套件）。
