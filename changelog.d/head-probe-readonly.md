### Fixed

- **#1278 canary HEAD proof 的 git 鏈段改為逐子命令唯讀 allowlist**：HEAD 探針鏈原本只看 git 子命令名稱，`git branch -D x`、`git worktree add|remove …`、`git symbolic-ref HEAD refs/heads/x`、`git log --output=<file>` 等寫入形態也被當成唯讀段收下；而 proof 只要求 bound HEAD 出現在任一輸出行，鏈中另一段（`git rev-parse main`、`git log --format=%H`）也能補上那一行。現在七個允許的子命令各有選項與位置參數的允許清單：`status` 只收短格式／porcelain／branch／untracked 等旗標與 worktree 內的 pathspec（`-v` 不收）；`branch` 只收 `--show-current` 與列表旗標，位置參數只在 `--list`／`-l` 下當樣式（`-d`／`-D`／`-m`／`-c`／`-f`／`-u`／上游設定／`--edit-description`／`--format` 與建立分支都不收）；`worktree` 只收 `list [--porcelain|-v|-z]`；`symbolic-ref` 只收讀一個 ref（`--short`／`-q`）；不當 proof 的 `rev-parse` 位置參數只收 HEAD 本身；不當 proof 的 `log`／`show` 只收縮寫 hash、統計、patch 與帶前綴的固定格式，`--output`、`--ext-diff`、`%H`／`%P` 與任何自訂 `--format`／`--pretty`（`%x61`、可能展開成空字串的 `%d`／`%b` 能把字面 hex 片段拼成任意 hash）、`--pretty=oneline`、`--no-abbrev-commit`、`--date=format:` 都不收。結果是能讓 git 印出單獨成行完整 commit hash 的只剩 proof 段本身，bound HEAD 那一行必出自印出 HEAD 的段。git 子命令集合不變（`tag`、`config`、`diff`、`rev-list` 等仍不收）；歷史 canary 形狀（#1279 報告的表）判定全部不變（#1278）。
